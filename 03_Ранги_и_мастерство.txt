# 📈 Ранги и мастерство

## Главное правило

У игрока нет жёсткого стартового класса.

Талант ≠ класс.

Персонаж может развивать несколько направлений одновременно и со временем создавать собственный путь развития.

Пример:
Мечник → развивал магию → освоил ауру → получил комбинированный путь развития.

Архимаг, Мастер меча и подобные высокие звания — результат развития, а не обязательный стартовый класс.

## ⭐ Таланты

Талант показывает природную предрасположенность к определённому направлению и не запрещает изучать другие направления.

Персонаж без таланта тоже может изучать направление, но развитие может быть сложнее/медленнее.

## ⚔️ Боевые ранги игроков

Зафиксированная схема для игроков:

**Новичок → Воин → Опытный воин → Мастер → Великий мастер → Мастер клинка → Легендарный мечник**

Эти ранги относятся к мастерству персонажа, а не являются обязательными классами.

## 🏹 Ранги лучников

**Новичок → Лучник → Опытный лучник → Мастер → Великий мастер → Мастер стрельбы → Легендарный стрелок**

## 🛡️ Ранги копейщиков

**Новичок → Копейщик → Опытный копейщик → Мастер → Великий мастер → Мастер копья → Легендарный копейщик**

## 🐎 Ранги кавалерии

**Новичок → Всадник → Опытный всадник → Мастер кавалерии → Великий всадник → Рыцарь → Легендарный рыцарь**

## 🔮 Ранги магов игроков

Для игроков выбран вариант без слова «Адепт»:

**Ученик → Маг → Высший маг → Великий маг → Архимаг → Верховный маг**

Это именно ступени мастерства магии.

- Ученик — основы.
- Маг — уверенное использование обычной магии.
- Высший маг — сложные заклинания и развитое направление.
- Великий маг — очень высокий уровень силы и контроля.
- Архимаг — исключительная боевая и магическая мощь.
- Верховный маг — крайне редкий высший уровень.

## ⚠️ Баланс

Высокий ранг не означает автоматическую победу. Итог зависит от таланта, опыта, состояния персонажа, экипировки, доступной силы магии, местности, командования и ситуации.

Ранги NPC могут использовать отдельную систему, если для конкретных категорий персонажей потребуется более подробная иерархия.
