# BOT — игровое ядро

Новая реализация игры. Старые документы в корне и `Разделы/` не изменяются.

## Цели

- Python 3.12+
- aiogram 3.x
- PostgreSQL + SQLAlchemy 2.x + Alembic
- Redis для временных состояний/кэша/блокировок
- строгая изоляция миров через `world_id`
- игровая логика в сервисах, а не в Telegram handlers
- Mini App только для карты мира и военной карты
- русская локализация интерфейса

## Первый этап

1. Базовая конфигурация.
2. Telegram bot `/start`.
3. PostgreSQL session/model base.
4. Глобальные пользователи и миры.
5. World context и проверки доступа.
6. Создание персонажа.
7. Главное inline-меню.
8. Alembic и Docker Compose.

## Важно

Критические игровые изменения выполняются в транзакциях PostgreSQL. `world_id` является обязательной частью всех мировых сущностей.
